# Проверка проекта — 20 октября 2026

Исходник: архив KCR.zip. Рабочая версия подготовлена отдельно; исходный архив не изменён. В архиве не было README, системы сборки, автоматических тестов и Git-истории.

## Результаты

**Исправленная версия: все 12 браузерных тестов прошли.** Использованы Playwright 1.62.1 и Chromium Headless Shell 151 в официальном контейнере mcr.microsoft.com/playwright:v1.62.1-noble (Linux ARM64). Внешняя сеть во время тестов отключена; приложение открывалось через локальный HTTP-сервер внутри контейнера.

В исходной версии базовая арифметика и независимость экземпляров проходят; регрессионные проверки выявляют описанные ниже проблемы. После полного прогона проверка повреждённой истории уточнена: теперь она проверяет отрисовку сразу после загрузки, до старта новой попытки. Уточнённый тест повторно запущен на обеих версиях: исходник не проходит, исправленная версия проходит.

Снимки [настольного](preview-desktop.png) и [мобильного](preview-mobile.png) интерфейса получены в браузере и просмотрены. На ширине 375 px горизонтального переполнения нет. Синтаксис JavaScript проверен через node --check. Локальный запуск Chromium на macOS был заблокирован ограничением системного сервиса, поэтому успешные результаты относятся к Linux-контейнеру, а не к Safari или нативному браузеру macOS.

## Устройство проекта

Статическая страница получает описание из data.json и создаёт три элемента mental-math-widget. Каждый элемент содержит собственный Shadow DOM, настройки, генератор примеров, таймер и историю ошибок. Сохранение выполняется в localStorage. Серверной части и внешних API нет. Библиотека Playwright добавлена только для тестов и не загружается посетителем сайта.

## Найденные и исправленные проблемы

| Проблема исходной версии | Изменение |
| --- | --- |
| Запрет доступа к localStorage или переполненное хранилище прерывали работу | Чтение и запись защищены; тренировка продолжает работать в памяти |
| Повреждённые элементы истории приводили к ошибке при отрисовке | Проверяются типы и значения записей; сохраняются до пяти корректных записей |
| Неверные data-level / data-duration давали некорректные настройки | Допустимые уровни и интервалы проверяются, предусмотрены значения по умолчанию |
| Изменение настроек сбрасывало таймер прямо во время тренировки | Элементы настройки блокируются на время попытки |
| Таймер считал вызовы setInterval и отставал при приостановке вкладки | Оставшееся время вычисляется по времени окончания; просроченные ответы не принимаются |
| Удалённый со страницы виджет продолжал отсчёт | disconnectedCallback останавливает тренировку; повторное подключение использует существующий экземпляр |
| Новый старт оставлял введённый ранее ответ | Поле очищается при старте |
| Виджеты без id записывали данные под одним общим ключом | Без id сохранение отключено; для сохранения требуется уникальный id |
| Фиксированные размеры и отсутствие viewport мешали работе на телефоне | Добавлены viewport, адаптивная компоновка и перенос текста |
| Ошибка загрузки data.json оставляла пустую страницу | Проверяется HTTP-статус и показывается видимое сообщение |

Добавлены язык страницы, кодировка, доступные имена полей, видимый клавиатурный фокус и более контрастные кнопки. Описание приведено в соответствие с реализацией: операции определяются уровнем, отдельно они не выбираются.

## Воспроизведение

```bash
npm install
npx playwright install chromium --only-shell
npm test
```

Сценарии: независимые экземпляры; арифметика на трёх уровнях; корректные и неправильные ответы; ограничение истории; перезагрузка; истечение таймера; фоновая приостановка; отказ хранилища; повреждённые записи; неверные атрибуты; отключение и повторное подключение; мобильная ширина; ошибка загрузки страницы; Enter; пустой ответ; повторный старт; экземпляр без id.

## Границы проверки

Браузерные тесты не являются доказательством отсутствия любых ошибок. Safari, Firefox и реальные мобильные устройства отдельно не проверялись. Синхронизация вкладок с одинаковым id не реализована. Динамическое изменение HTML-атрибутов не отслеживается. Системное изменение часов может влиять на отсчёт времени. Нет аккаунтов, серверного хранения и полной истории тренировок.
